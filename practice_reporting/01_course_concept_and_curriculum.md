# Концепция и учебный план

## 1) Краткое описание продукта

**ML Interactive Course** — интерактивный учебный продукт по основам машинного обучения: теория + прогресс + практики + визуальные симуляторы + финальный проект с проверкой.

## 2) Формат

- веб‑платформа (Next.js) + API (FastAPI) + БД прогресса (SQLite/SQLAlchemy).

## 3) Целевая аудитория

- студенты/джуниоры, которым нужен практический вход в ML без перегруза математикой;
- базовый Python приветствуется.

## 4) Ценность

- обучение “через действие”: симуляторы показывают влияние параметров на метрики и поведение моделей;
- финальный проект проверяется автоматически (метрики) + при наличии ключа — AI (GigaChat) даёт рекомендации.

## 5) Результаты обучения

После курса студент сможет:
- объяснить разницу между регрессией/классификацией/кластеризацией;
- подготовить табличные данные (пропуски, категориальные признаки, масштабирование);
- обучить базовые модели (Linear/Logistic Regression, kNN, K‑means);
- выбрать и интерпретировать метрики (MSE/R², accuracy/precision/recall/F1, silhouette/WCSS);
- понимать и диагностировать переобучение, применять регуляризацию;
- выполнить мини‑проект по регрессии на предоставленном датасете и сдать артефакты (`predictions.csv` + код/отчёт).

## 6) Структура курса: модули и уроки

Источник: `README.md`, `backend/init_db.py`.

### Модуль 1 — Введение и основы данных
- **Урок 1**: Введение в ML (типы задач ML; симулятор типов задач)
- **Урок 2**: Основы работы с данными (типы данных, признаки, сплиты, предобработка; симулятор работы с данными)
- **Урок 3**: Линейная регрессия (симулятор + метрики MSE/R²)

### Модуль 2 — Классификация
- **Урок 4**: Логистическая регрессия и бинарная классификация (граница решений; метрики)
- **Урок 5**: kNN (выбор k; границы решений)

### Модуль 3 — Оценка качества
- **Урок 6**: Метрики качества (accuracy/precision/recall/F1, сценарии дисбаланса; сравнение метрик)

### Модуль 4 — Обобщающая способность
- **Урок 7**: Переобучение и регуляризация (train vs val error; симулятор)

### Модуль 5 — Кластеризация
- **Урок 8**: K‑means (центроиды, elbow method, silhouette)

### Модуль 6 — Итоговый проект
- **Урок 9**: Финальный проект (регрессия; скачивание данных; загрузка `predictions.csv` + код/отчёт; авто‑метрики + опциональный AI‑фидбек)

## 7) Таймлайн прохождения

Пример на 3 недели (можно адаптировать под практику/семестр):
- **Неделя 1**: уроки 1–3 + мини‑практика на табличных данных.
- **Неделя 2**: уроки 4–6 + практикум “подбор метрики под задачу”.
- **Неделя 3**: уроки 7–9 + сдача проекта (артефакты + разбор).

## 8) Примеры заданий и практических кейсов

### Пример практического кейса (финальный проект)

Кратко: задача регрессии на табличном датасете (признаки `x1..x6`, категория `region`, пропуски). Нужно подготовить данные, обучить модель и сдать `predictions.csv` (`id`, `y_pred`) + опционально код/отчет.

### Примеры тестовых вопросов (промежуточная проверка)

В `backend/init_db.py` для уроков seeded вопросы (multiple choice / numeric / text). Примеры:
- “Что такое машинное обучение?”
- “Какой тип задачи решает классификация?”
- “Какой из примеров относится к задаче регрессии?”

## 9) Формы промежуточной и финальной аттестации

### Промежуточная аттестация

- короткие квизы по урокам (база вопросов в БД);
- выполнение интерактивных симуляторов с фиксацией прогресса.

### Финальная аттестация

- сдача проекта (урок 9): авто‑проверка метриками (R², RMSE) + опциональная AI‑рецензия (GigaChat) по коду/описанию.

## 10) Критерии качества и актуальности

- контент покрывает базовый “скелет” ML (данные → модели → метрики → обобщение → кластеризация → проект);
- упор на практику и визуализацию снижает порог входа;
- есть “производственный” формат сдачи проекта через артефакты (CSV + код/отчет).
