# Отчетность по практике

Эта папка содержит **все артефакты для отчетности по практике** по проекту из корня репозитория (кроме итоговой презентации).

## Содержание

- `01_course_concept_and_curriculum.md` — концепция и учебный план (структура, модули, таймлайн, примеры заданий, форматы аттестации)
- `02_demo_ai_simulators.md` — демо симуляторов и AI‑ассистента (ссылка/видео + инструкция запуска)
- `03_launch_and_pilot_report.md` — отчет запуска и апробации (охват/вовлеченность/успеваемость, срез до→после)
- `04_engagement_report.md` — вовлечённость: посещаемость/активность/выполнение практик
- `05_student_feedback.md` — обратная связь студентов (анкета + как собирать/суммаризировать)
- `06_expert_review.md` — рецензия экспертов и координатора (шаблон + критерии)

## Дополнительно

- `templates/` — шаблоны CSV/таблиц для заполнения метрик и опросов

## Как использовать

- Если у вас есть реальные данные апробации (список студентов, даты, результаты), внесите их в файлы `03_*`, `04_*`, `05_*`.
- Если данных ещё нет — используйте документы как **корректные шаблоны** с пометками `TODO`.
- Для автоматической выгрузки базовых метрик запустите `tools/extract_pilot_metrics.py` (см. инструкцию в `03_launch_and_pilot_report.md`).
